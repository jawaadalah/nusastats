NusaStats — portal statistik Indonesia: penduduk, ekonomi, tenaga kerja, kemiskinan, dan perbandingan provinsi, dari angka resmi BPS dan World Bank dengan sumber dan tahun yang jelas. Situs statis tanpa pelacakan, dengan grafik SVG, pemilih tahun, pengurut tabel, dan pencarian provinsi yang semuanya berfungsi.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — juga berfungsi di layar ponsel.
